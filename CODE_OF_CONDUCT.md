# Community code of conduct

This policy applies to project issues, pull requests, reviews and project-managed spaces. Respect participants across backgrounds, identities and experience levels. Provide constructive feedback, protect privacy and give credit. Harassment, discrimination, threats, sexualized attention, doxxing and disclosure of confidential information are unacceptable.

For a public incident without sensitive details, use GitHub report-content controls or request maintainer review of the thread. For private abuse reports use https://support.github.com/contact/report-abuse. This is a GitHub platform route, not a project-operated mailbox. No private project conduct contact or dedicated enforcement team is established; creating one remains an owner task before community launch.

Maintainers with actual permissions may remove harmful content, request corrections, restrict participation or refer abuse to GitHub, considering severity, recurrence and participant safety. Affected participants may request reconsideration through an available maintainer channel without publishing private evidence. No confidential project appeal channel, independent enforcement capacity or response SLA is claimed. Do not retaliate against good-faith reports.
