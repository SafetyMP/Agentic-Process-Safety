# Support

Start with the [README](README.md), [architecture](docs/ARCHITECTURE.md) and [readiness audit](docs/open-source-readiness.md) for setup, evidence limits and pending human review. See [CONTRIBUTING.md](CONTRIBUTING.md) for checks.

On the actual repository, open a sanitized bug or question issue if Issues is enabled. Include revision, OS, Node/Python/OPA versions, commands, expected/actual behavior and a minimal synthetic reproduction. Remove secrets, personal information, operational data and confidential reference answers. Issue availability is unverified; there is no response SLA or commercial support commitment. Use [SECURITY.md](SECURITY.md) for vulnerabilities and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns.

This project provides no industrial safety approval, risk acceptance or certification. Qualified humans must review evidence and authorize operational decisions outside this sandbox.
