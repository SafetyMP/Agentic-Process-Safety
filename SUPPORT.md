# Getting help with APS

Try the [live app](https://safetymp.github.io/Agentic-Process-Safety/) and follow the [user guide](docs/USER_GUIDE.md) from comparison to a reasoned next step. The [vision](docs/VISION.md) explains the research question; the [documentation map](docs/README.md) separates current guidance from implementation references and historical records. For development, start with [Contributing](CONTRIBUTING.md).

## Choose the right report

- **Bug:** a broken interaction, incorrect retained result, missing link or reproducible runtime failure.
- **Question:** using the app, understanding a case, running a command or interpreting an evidence boundary.
- **Research or design proposal:** a clearer investigation, a proposed case or control, a competing explanation, or evidence needed to assess a claim.
- **Vulnerability:** follow [Security](SECURITY.md) privately. Do not include vulnerability details in a public issue.

Use the [issue chooser](https://github.com/SafetyMP/Agentic-Process-Safety/issues/new/choose). For an app report, include the route, selected case, input values, sequence of actions, browser/OS and viewport when relevant. State whether the observation concerns an illustrative comparison or a recorded trial. For a CLI report, include the commit, runtime versions, exact commands and a minimal synthetic reproduction. Remove secrets, personal information, operational data and confidential reference answers; review exported discussion notes before sharing them.

## What support can establish

Support can help explain modeled behavior and investigate defects. A discussion recommendation, successful test or sandbox trial does not establish that a real purchase should proceed, that a hazard has human approval, or that a system is safe. Operational decisions and risk acceptance remain outside this project.

There is no response SLA or commercial support commitment. Use the [code of conduct](CODE_OF_CONDUCT.md) for participation concerns and the [current owner decisions](docs/open-source-readiness.md#current-owner-decisions) for unresolved maintenance and review responsibilities.
